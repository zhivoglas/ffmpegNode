# ffmpegNode Stream 🚀
**The Universal Visual Logic Engine for Media & Beyond**

**ffmpegNode Stream** is a modular, engine-agnostic orchestrator for media processing. It transforms complex code and CLI logic into an intuitive **visual node graph**. Built for creators, developers, and power users who value both power and aesthetics.

---

### 🎨 Visual & Immersive Experience
We believe that professional tools shouldn't be boring.
*   **Animated Workspaces:** Choose from stunning animated backgrounds to keep your creative flow inspired.
*   **Sponsorship Hub:** Our interface features dedicated spaces to showcase **Sponsors and Patrons** right in the app header and backgrounds.
*   **Modern UI:** A sleek, high-performance interface built with React 19, Vite, and Framer Motion.

### 🧩 Engine-Agnostic Architecture
The project is built on a **"Plugin-Worker"** model. While it has deep FFmpeg integration, the core can host **any engine**:
*   **Multi-Engine Support:** Run FFmpeg, OpenCV, AI Upscalers, or Custom Scripts in a single pipeline.
*   **Manifest-Driven UI:** Nodes and controls are automatically generated from a simple `manifest.json`.
*   **Modular Backend:** Add new capabilities by just dropping a folder into `/plugins`.

### 🚀 Getting Started

#### 1. Prerequisites
*   **Node.js** (v18.0.0+)
*   **Python** (v3.10+)
*   **FFmpeg** (Optional, recommended for default plugins)

#### 2. Installation & Run
```bash
# Clone the repository
git clone https://github.com
cd ffmpegNode

# Setup & Start Frontend (Electron + React)
cd frontend
npm install
npm run start

# Start Backend Orchestrator (Run this in a separate terminal)
cd ..
python main.py
```
